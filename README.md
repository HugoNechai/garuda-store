# Nine Shuttles

Full-stack e-commerce platform built for a real business.

## Features

- Product catalog
- Shopping cart
- User authentication
- Admin dashboard
- Order management
- Stripe payments
- PayPal payments
- Email notifications

## Tech Stack

- Next.js
- TypeScript
- Prisma
- PostgreSQL
- Stripe
- PayPal
- Resend
